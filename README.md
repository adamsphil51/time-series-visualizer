# Time Series Visualizer

This project visualizes page view data from the freeCodeCamp forum using Python, Pandas, Matplotlib, and Seaborn. 

## Features
- **Line Plot**: Daily forum page views from 5/2016 to 12/2019.
- **Bar Plot**: Average daily page views for each month grouped by year.
- **Box Plot**: Year-wise and month-wise distribution of page views to show trend and seasonality.

## Files
- `time_series_visualizer.py`: Python script containing all visualization functions.
- `fcc-forum-pageviews.csv`: CSV data file with daily forum page views.
- Plots are saved as `line_plot.png`, `bar_plot.png`, and `box_plot.png`.
